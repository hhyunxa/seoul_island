# 두근두근 서울섬

실제 서울 모양(25개 구)의 섬을 동글동글한 주민 캐릭터로 걸어 다니며 명소를 구경하고, 주민들이 준비한 미니게임 23종을 즐기는 3D 데모예요.

- **플레이:** https://hhyunxa.github.io/seoul_island/
- 설치 없이 브라우저만 있으면 돼요. 진행 상황(벨, 최고 기록, 낚시 도감)은 그 브라우저에 저장돼요.
- 예전 서울섬 데모(노들섬 광장 버전)는 [`legacy.html`](legacy.html)에 그대로 있어요.

## 시작하기

1. **주민 등록:** 이름을 정하고 사람·토끼·고양이·곰·강아지·다람쥐·양·사슴 중에서 고른 뒤 색을 골라요.
2. **서울섬으로 출발:** 광화문광장에서 시작해요. 월드에서 Esc를 누르면 다시 꾸미기로 돌아가요.

## 조작

| 키 | 동작 |
|---|---|
| WASD / 방향키 | 이동 (Shift 달리기) |
| 땅 클릭 | 그곳으로 걷기 |
| Space | 점프 |
| E | 말 걸기 · 안내판 읽기 · 지하철/수상택시 타기 |
| 드래그 / 휠 | 시점 회전 / 확대·축소 (R 시점 초기화) |
| M | 큰 지도 |
| T 또는 🚕 버튼 | 택시 부르기 |

## 서울섬에서 할 수 있는 것

- **맵:** 실제 서울 구 경계를 따라 만든 섬, 한강과 한강 다리 14개, 지천. 쓸모없는 빌딩은 없고 동글 나무·벚꽃·은행나무·꽃으로 채웠어요.
- **명소 안내판 43곳:** 경복궁, 남산서울타워, DDP, 롯데월드타워, 63빌딩 등. E로 설명을 읽어요.
- **주민과 미니게임 23종:** 노란 별 옆 주민에게 말을 걸면 "할래?"라고 물어봐요. 점수만큼 벨을 받아요.
  과일 받기(경동시장) · 낚시(노량진) · 닭 몰이(암사동) · 벌레 잡기(노들섬) · 해변 달리기(여의도) · 3:3 축구(월드컵경기장) · 오리배 레이스(성동구) · 사랑의 자물쇠(남산타워) · 캐치볼(고척돔) · 동물 먹이 주기(어린이대공원) · 카트(도봉운전면허시험장) · 코인노래방 · 인형뽑기(홍대) · 길 안내(명동) · 퍼레이드(이태원) · 비행기 조종(김포공항) · 스트리트 스냅(성수동) · 홈런 더비(잠실야구장) · 지휘자(예술의전당) · K-팝 포즈(강남역) · 로봇 공장(가산) · 물 주기(서울식물원) · 무한의 계단(63빌딩)
- **교통:** 지하철 2호선 6개 역, 한강 수상택시 직접 운전(선착장 4곳), 벨을 내는 택시.
- **하루의 흐름:** 실제 7초 = 게임 10분. 해가 지면 화면이 노을 테마(Gowun Batang 글씨·보랏빛)로 바뀌고 가로등이 켜져요.
- **팔각정 야경 투어:** 북악스카이웨이 팔각정 망원경. 밤에 보면 처음 한 번 +50벨.
- **웹캠(선택):** 손 인식 10종·몸 인식 2종 게임은 카메라로도 할 수 있어요. 영상은 브라우저 밖으로 나가지 않아요. https 주소나 localhost에서만 켜져요.

## 구조

빌드 없이 `index.html` + `js/` ES 모듈로 동작해요. three.js(0.186.1)와 MediaPipe는 jsDelivr CDN에서 불러와요.

```
index.html        화면 틀 (주민 등록 · 월드 HUD · 미니게임 HUD), importmap
css/style.css     서울섬 테마 (낮: Jua, 노을: Gowun Batang)
js/toon.js        그림체: 툰 셰이딩 · 색 보정 · 둥근 상자 · 휘는 지평선
js/character.js   동글동글 주민 캐릭터 (사람 + 동물 7종)
js/world.js       서울 모양 섬 · 바닥 · 나무 · 동물 · 미니맵
js/npcs.js        미니게임 주민과 대사
js/seoulMap.js    서울 타일맵 (구 경계, 한강, 다리, 명소 자리)
js/landmarks.js   명소 모형
js/minigames/     미니게임 23종 (base.js 공통 뼈대)
js/main.js        화면 전환 · 입력 · 카메라 · 대화 · 교통 · 저장
```

로컬에서 실행하려면 이 폴더에서 정적 서버를 띄우면 돼요.

```bash
python3 -m http.server 8765
```
